Privacy Policy

Last updated: 26 November 2026

1. Summary

Shorts Autopilot is used only by its operator to publish the operator's own videos. It does not collect, sell or share personal data of anyone else.

2. Data the tool uses

  • Access tokens for the operator's own YouTube, Instagram and TikTok accounts, granted by the operator through each platform's official login. They are stored only on the operator's own computer and are used only to upload videos and read the resulting post links.
  • Basic account information (account ID and username) returned by the platforms, used only to publish to the right account.

3. Data the tool does not collect

The tool has no public users. It does not read followers, viewers, comments, messages or any other data about third parties, and it uses no cookies or analytics.

4. YouTube API Services

Shorts Autopilot uses YouTube API Services to upload videos to the operator's own YouTube channel. By using it you agree to the YouTube Terms of Service, and data accessed through YouTube API Services is also subject to the Google Privacy Policy. The tool reads only the operator's own channel ID and title and stores no YouTube data other than the access token on the operator's computer. Access can be revoked at any time on the Google security settings page.

5. Retention and deletion

Tokens are kept until the operator removes them or revokes access in the platform's settings (Google account permissions, Instagram "Apps and websites", TikTok "Manage app permissions"). Deleting the local configuration file removes all stored credentials.
